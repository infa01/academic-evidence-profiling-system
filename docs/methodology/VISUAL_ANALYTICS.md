# Visual Analytics

The dashboard and PDF include visual analytics to make the structured evidence
profile easier to inspect. The visuals are explanatory summaries, not standalone
proof of professional competence.

## Visual Analytics Purpose

The visual layer supports four goals:

- make ranked academic evidence signals easier to compare;
- show how cognitive depth is distributed across module levels;
- summarise broader semantic skill areas;
- expose ESCO occupation-orientation signals without hiding weak/noisy links.

Each visual should be interpreted alongside the XAI tables, methodology notes,
RAG evidence and limitations.

## Current Visuals

### 1. Top Academic Evidence Signals

Generated by:

```text
scripts/visualise_top_skills.py
```

Output:

```text
output/charts/top_skills_bar_chart.png
```

This chart ranks ESCO-aligned skill evidence by academic evidence strength.
Longer bars indicate stronger evidence within the current student profile.

How to read it:

- compare which ESCO skills have stronger academic evidence;
- use it as a ranked summary of the calibrated skill profile;
- interpret scores as evidence strength, not professional mastery.

What not to conclude:

- a high bar does not mean the student is professionally certified;
- the chart should not be used for hiring or selection decisions.

### 2. Bloom Cognitive Depth by Module Level

Generated by:

```text
scripts/visualise_bloom_distribution.py
```

Output:

```text
output/charts/bloom_distribution_chart_with_ambiguity.png
```

This chart shows Bloom cognitive-depth evidence across academic module levels.
It helps explain whether evidence comes from foundational, intermediate or
advanced modules.

How to read it:

- module levels show approximate academic progression;
- Bloom categories show inferred cognitive demand from learning outcomes;
- `Mixed/Ambiguous` is retained when top Bloom candidates are near-tied;
- `Unclassified` is retained when the Bloom classifier avoids overclaiming.

What not to conclude:

- Bloom classification is approximate;
- near-tie handling reduces overclaiming but does not replace clause-level
  multi-label classification;
- cognitive depth inferred from learning outcome text does not prove achieved
  learning depth.

### 3. Semantic Domain Strength

Generated by:

```text
scripts/visualise_domain_strength.py
```

Output:

```text
output/charts/domain_strength_bar_chart.png
```

This chart ranks semantic skill domains by the average academic evidence of
their included ESCO skills.

How to read it:

- domains summarise broader areas of skill evidence;
- stronger domains indicate areas where multiple ESCO signals cluster together;
- domain labels are interpretive and generated from clustered ESCO skills.

What not to conclude:

- semantic domains are not official ESCO categories;
- domain strength is not a validated measure of professional specialization.

### 4. ESCO Occupation Orientation

Generated by:

```text
scripts/visualise_occupation_orientation.py
```

Output:

```text
output/charts/occupation_orientation_bar_chart.png
```

This chart shows the top ranked ESCO occupation-orientation signals.
Occupation signals are derived from ESCO skill-to-occupation relations and
weighted by supporting academic skill evidence.

How to read it:

- higher bars indicate stronger ESCO-based orientation evidence;
- signals should be compared with their supporting skills and evidence category;
- the dashboard retains weak/noise links separately for transparency.

What not to conclude:

- this is not a career prediction;
- this is not a job recommendation;
- ESCO occupation links can be broad and noisy.

### 5. Module-to-Domain Heatmap

Generated by:

```text
scripts/visualise_clustered_heatmap.py
```

Output:

```text
output/charts/clustered_domain_heatmap.png
```

This heatmap shows how modules contribute to semantic skill domains.

How to read it:

- rows represent modules;
- columns represent semantic domains;
- stronger colour indicates stronger module contribution to a domain.

What not to conclude:

- a low value does not mean the module is unimportant;
- it only reflects extracted evidence under the current Bloom/ESCO pipeline.

## Visual Selection Rationale

The selected visuals cover different interpretability questions:

| Visual | Main Question |
| --- | --- |
| Top skill evidence | Which ESCO skills have the strongest academic evidence? |
| Bloom by module level | What cognitive-depth evidence appears across academic levels? |
| Domain strength | Which broader semantic skill areas are strongest? |
| Occupation orientation | Which ESCO occupation directions appear from skill relations? |
| Heatmap | Which modules contribute to which domains? |

Together, they support explainable interpretation without reducing the project
to a single score or a single career suggestion.

## Thesis-Safe Interpretation

A suitable dissertation phrasing is:

> Visual analytics are used to summarise the structured academic evidence profile
> and support explainability. Each visual answers a specific interpretive
> question about skill evidence, Bloom depth, semantic domains, module
> contribution or ESCO occupation orientation. The visuals are not standalone
> assessments of ability; they are explanatory views over the evidence pipeline.
