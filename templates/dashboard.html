Methodology / Help

How does the system generate the academic evidence profile?

The system analyses completed modules, learning outcomes, Bloom cognitive evidence, ESCO skill relevance, student performance signals, semantic similarity scores, and ESCO occupation-orientation signals. Scores are used as academic evidence-strength indicators for explainability and RAG retrieval, not as professional certification.

How should scores be interpreted?

Raw scores are conservative composite indicators of academic evidence strength. Academic normalized scores are calculated against the theoretical academic evidence ceiling of the scoring model and should not be interpreted as professional mastery percentages. Relative profile rank is used only to compare skills within the same student profile.

How is the AI report generated?

The employability report is generated locally using the selected Ollama model. Before generation, the system retrieves structured evidence chunks from the final student profile and builds a RAG-grounded prompt. The model is instructed to use only that retrieved evidence.

{% if rag_evaluation_metrics or targeted_rag_evaluation_metrics %}
How were RAG/LLM outputs evaluated?

The prototype includes lightweight RAGAS-inspired proxy checks for context precision, section relevance, faithfulness, answer relevance, and evidence mention coverage. These scores are used as technical quality signals, not as proof that the generated advice is clinically or professionally validated.
