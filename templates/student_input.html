View / Edit Current Employability Report Prompt

This prompt is used by the local LLM during employability report generation. If left empty, the system will use the default evidence-based prompt. If a custom prompt is provided, it will replace the default writing instructions while the structured competency evidence will still be generated by the pipeline. Custom prompts should be edited carefully to avoid overclaiming, unsupported claims, or instructions that conflict with the evidence-based nature of the report.

Available Prompt Variables

If you edit the prompt, you may use the following placeholders to insert the structured competency evidence generated by the system.

{{ '{{student_id}}' }} Inserts the current student ID.
{{ '{{skill_lines}}' }} Inserts the calibrated top skills, scores, evidence levels and modules.
{{ '{{domain_lines}}' }} Inserts the generated competency domains and their included skills.

For reliable report generation, custom prompts should normally include {{ '{{skill_lines}}' }} and {{ '{{domain_lines}}' }}. Otherwise, the local LLM may not receive enough structured evidence to produce a grounded employability report.
